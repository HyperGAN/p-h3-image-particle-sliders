# P-H3-Image Particle Sliders

Source-only repository for the proposed PrunaAI/P-H3-Image Particle Sliders integration.

The initial implementation is prepared on a review branch. It uses the shared
HyperGAN/particle-sliders library and unrelated synthetic CPU checks. Native
model download, loading, training, rendering and model publication are disabled
pending model-license authorization and native qualification. No model weights,
trained adapters or model outputs are included.

See the repository pull request for source, validation evidence and next steps.
